# AI Starter Project (Student Version)

## Goal
Implement a small-scale training pipeline for a supervised model or a tiny language model:
- baseline model
- at least one ablation

## Required deliverables
1) Topic card(s) describing:
   - objective, loss, metrics, assumptions
2) Reproducible training code:
   - `pyproject.toml`
   - deterministic seeds
   - tests (tokenization/label shift if LM)
3) Evaluation report:
   - metrics + failure cases
   - ablations and conclusions

## Suggested tasks
- Classification with a small dataset
- Tiny transformer on a toy corpus
- Compare optimizers (SGD vs AdamW) or schedules

## LLM usage
Use LLMs to:
- propose alternative derivations and sanity checks
- generate test cases and debug checklists
- propose ablation plans, then you execute and interpret results

## Ethics
No copy-paste. Verify all citations. Document assistance.
